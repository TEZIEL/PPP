- 다운로드 날짜: 2026년 5월 6일
- 라이선스명: 전부 CC0 / Creative Commons Zero로 정리
- 크레딧 필요 여부: No
- 상업 이용 가능 여부: Yes
- 변형 가능 여부: Yes
- 원본 파일 보관 여부: Yes
- Audacity 프로젝트 보관 여부: 현재 없음
- 비고: Signature Sounds의 `London Underground/Tube Recordings`는 개별 상품 페이지에 CC0 표기가 명확히 보이지 않을 수 있으므로, Signature Sounds About 페이지의 사이트 전체 CC0 선언 스크린샷을 함께 보관합니다.
